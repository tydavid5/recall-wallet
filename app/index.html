Intents — fund from any chain, no bridging

Powered by Aurora's Intents Swap Widget (NEAR Intents, 35+ chains). Connect a wallet, pay with a token on any supported chain, and Intents settles it to NEAR — then the vault's policy governs what happens next. No manual bridging, no multi-step swaps.

How it works: 1) Connect your wallet inside the widget. 2) Choose a source chain and token. 3) Intents quotes, you approve the deposit in your own wallet, and it settles to NEAR. 4) The Recall Wallet Agent vault (testnet, separate from this widget) then applies its policy to spending.

Honest labels: the widget runs on mainnet Intents infrastructure — if you use it, you approve real amounts in your own wallet, so only use amounts you choose. Muse never touches your funds and no key is involved here. The vault demo itself stays testnet-only. Every widget integration needs an API key from Widget Studio, and that key must never be committed to a public repo — so this panel loads the widget from a link you paste, stored only in your browser.

Open Widget Studio → Integration docs

To get your link: in Widget Studio, log in with email → choose Swap widget mode → configure networks/tokens → Embed in your app → Generate a new link to embed → paste that link below.

About Recall Wallet Agent

An agent wallet with a memory and a conscience, built for the NEAR Hackathon. Plain-language payments are checked against remembered spending rules before anything moves, and every block names the rule that stopped it.

Testnet only. Intents settlement is mainnet-only, so this demo shows the policy check, derived addresses, and one real testnet execution — never a faked settlement.
